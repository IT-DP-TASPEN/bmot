# DWH source audit (read-only, 24 September 2026)

Formula reference: local SALAK `fincloud-integration` checkout at `a3226b1` (`app/Models/BranchOffice.php`). Source-ingestion reference: local `dwh-v2` checkout at `05a99c0`.

Live schema and sampled rows were inspected on `dwhv2` using read-only transactions. The latest common snapshot of the four source tables is **2026-09-23**. Savings and deposits begin on 2025-10-13; loans on 2025-10-14; balance sheet on 2025-10-12. All four tables have `as_of_date`. `requested_date` in the EOD tables matched `as_of_date` in sampled rows. Balance-sheet `period_from` and `period_to` describe a source load interval: they matched `as_of_date` on 2026-09-23, but January–July 2026 snapshots had `period_from=2026-01-01` and `period_to=2026-07-31`. Position queries must use `as_of_date`.

Source checks on 2026-09-23: savings had 36,908 rows, of which 18 were `TAB_INTERNAL` and 40 were ABP; no `RAK` appeared that day. Eligible savings total was 136,507,102,414.32 and ABP was 19,717,136,470.33. Deposits had 2,693 rows, with product 203 present and 204 absent in all audited dates. Loans had 10,385 unique account numbers; collectability values were 1–5. The balance sheet had one load, nine branch scopes, and one row per requested COA per branch. Monetary source columns are text; savings and balance sheet amounts include comma thousands separators, while balance sheet negatives use `<...>`.

Cash Ratio assumption, confirmed by the dashboard owner: use zero for `branch_saldo_aba_blokir`. SALAK normally subtracts this value from its `branch_offices` application table; the DWH has no matching column or branch table. This dashboard's Cash Ratio will therefore differ from SALAK if any blocked ABA balance is nonzero. The dashboard owner confirmed `pokok_pinjaman` as Booking nominal. The EOD snapshot cannot include loans booked and fully closed before the reporting date.

NIM needs monthly productive-asset samples from January through the selected month. The sample date uses SALAK/Carbon's `setMonth` overflow behavior (for example, the February sample for a March 31 report is March 3). Because Fincloud balance-sheet history starts in October 2025, NIM is hidden for 2025 reporting dates rather than displayed as zero from incomplete history. NPL is hidden on dates with no loan snapshot.
